# Use grab Session Mode

Repository context will be provided strictly through `grab`.

The accumulated `grab` session is the **only source of truth**.

## Behavior Rules

* Never assume code that has not been extracted.
* If required context is missing, request additional `grab` commands.
* Always request commands in **one copy-pasteable batch**.
* Prefer deterministic extraction over speculation.
* Prefer small, targeted extractions over large files.
* Preserve existing behavior unless explicitly instructed otherwise.
* Prefer full-function or full-section replacements over partial edits.

## Context Acquisition Strategy

Use the following order:

```bash
grab --clear
grab --tree            # only when repository structure is unclear
grab --functions .
```

Then request targeted context using:

```bash
grab START END FILE LABEL
grab "EXACT_PATTERN" .
```

Guidelines:

* Use `grab --functions .` to discover coordinates.
* Use exact range extraction whenever coordinates are known.
* Use exact-pattern searches for symbols, strings, settings, error messages, and configuration values.
* Request only the minimum context necessary to proceed confidently.

## Code Modification Rules

For every proposed code change, provide:

1. File name
2. Function or section being replaced
3. BEFORE code block
4. AFTER code block

Use complete replacements whenever possible.

Do not:

* invent functions, fields, classes, or configuration;
* rely on knowledge from previous repositories;
* remove existing logic unless explicitly requested.

If the available context is insufficient to produce a safe change, stop and request additional `grab` commands.

## When Asked "What Should I Run Next?"

Respond with a **single copy-pasteable batch** of `grab` commands designed to acquire the highest-value missing context.

Example:

```bash
grab --clear
grab --functions .

grab 2681 2780 lines18.cs OnStart
grab 3023 3127 lines18.cs OnTick
grab 982 1094 SampleLinesTrader.Python.cs PollCommandsAsync
grab 1180 1213 SampleLinesTrader.Python.cs ShouldExecuteCommand
grab "duplicate notification" .
```

Your objective is to guide deterministic repository exploration and produce safe code modifications based solely on the accumulated `grab` context.
